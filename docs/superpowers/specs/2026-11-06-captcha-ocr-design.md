# 本地验证码自动识别设计

用户已选择将一次性人工识别改为以后自动识别，覆盖默认账号网页登录和后台会话失效后的重新认证。

方案：在 Mac mini Docker 中运行离线 ddddocr，后端仅发送验证码图片，每张图最多尝试 5 次、最多主动更换 3 次（共最多 4 张图、20 次识别提交），每张图只获取一次并依次使用原图、放大、灰度拉伸、两种二值化方案，学校返回的新 state 用于下一次识别。不使用云端模型或付费服务。OCR 失败、超时或连续拒绝后回退现有人工挑战；账号密码明确错误等其他错误不重试。保留默认账号认证并发合并和人工挑战单次消费机制。

配置：新增可选普通配置 ICLASS_CAPTCHA_OCR_URL，空值关闭，Compose 默认指向私有 OCR 容器。无新增秘密。OCR 不发布宿主机端口，不存图、不记录图片、验证码、密码或 Cookie。

验证：遵循用户要求，不新增或在实现期间运行单元测试，结束后统一运行现有检查、构建及真实认证验证。部署前保留旧后端镜像用于回滚。只本地提交，不推送或合并远端。
